### 🚀 Что я делаю и изучаю

* 💻 **Backend & Architecture:** Проектирую надежные REST API, работаю с реляционными и NoSQL базами данных. Сейчас активно углубляюсь в GraphQL и микросервисы (Docker).
* 🧪 **Quality Assurance:** Тестирую комплексно. Работаю с Postman и Swagger, внедряю базовые практики кибербезопасности на этапе написания кода.
* 🎨 **Frontend-Friendly Backend:** Знаю Vanilla JS и основы фронтенда на том уровне, который позволяет писать чистые контракты для UI без костылей.
* 🎯 **Вектор развития:** Вырасти в уверенного Middle Backend-инженера через хардкорную практику на коммерческих и пет-проектах.
